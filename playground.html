    Como este ambiente funciona
    O compilador Eclipse ECJ gera bytecode com sintaxe Java 17, executado pelo CheerpJ no navegador. As assinaturas de biblioteca disponíveis para compilação são as de Java 8, suficientes para as atividades desta apostila. APIs posteriores, records, projetos com pacotes e dependências externas devem ser executados em um JDK local.
    Cada etapa de compilação ou execução tem limite de 60 segundos. O carregamento inicial tem até 120 segundos, e a saída é limitada a 50 mil caracteres. Interromper reinicia a JVM e preserva o editor. Ao trocar de atividade, cada rascunho fica salvo separadamente neste navegador.
    Execução com CheerpJ, da Leaning Technologies, e Eclipse JDT. Os recursos da JVM são obtidos do CDN do CheerpJ. O site não envia seu código a um serviço remoto de compilação.
    

    O rascunho será salvo neste navegador. Use exportar para guardar uma cópia.

    Playground sem internet
    

    Você está offline. Compilar e executar Java fica indisponível até a conexão voltar, pois o ambiente precisa carregar recursos da JVM pela internet.
    Você pode continuar lendo as atividades já carregadas, editar o código e exportar seus rascunhos. Eles continuam salvos neste navegador.
    Ao se reconectar, o aviso fecha automaticamente. Execute novamente para testar seu código. A compilação acontece no próprio navegador.
